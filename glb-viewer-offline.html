Game profile

Target sizes load from the game repo. Load or drop a targets.json to use another copy.
"Make game-ready" scales to the id's target height, moves the pivot to the base centre, uses the face budget and 512 WebP base-colour textures, then applies.

    Transform

    1 unit = 1 metre. These change the model itself; the result is cleared, press Apply again.

    Resolution (faces)

    100%
    Below 100% decimates (removes faces). Above 100% subdivides first, then trims to the exact target.
    10%
    Caps how far decimation may deform the shape (relative to model size). Raise it if the face target isn't reached.

    Smoothness

    0
    Taubin smoothing passes. Removes bumps and faceting without shrinking the model.

    File size

    When on, faces are reduced further (if needed) until the exported GLB fits.
    Drops normal, roughness, metal, AO and emissive maps on export (flat roughness 1, metal 0), as the game's ingest does. "Keep" writes the original image bytes when no resize is needed.
