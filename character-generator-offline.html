Mystical Character Generator

Procedural fantasy characters, exported as GLB. Open the result in the GLB viewer & optimizer to smooth it or change its face count.

Character

The same archetype and seed always give the same character. For the game's NPCs pick a Townsfolk archetype: it switches on the game set (chibi look, KayKit size, KayKit skeleton, one palette material, game budget and game materials). Other archetypes switch it off again.

Body

Big head and short legs like the KayKit Adventurers, with the joints exactly where their skeleton has them, so KayKit animations fit. Off: realistic proportions.
With the chibi look: the file is in KayKit units at KayKit's own size (about 2.2 to 2.4 units to the top of the hair; Knight.glb is 2.3 to the top of its head, Rogue and Mage 2.2), so the game scales it exactly like its KayKit characters (0.78 in Embers, about 1.7 to 1.9 m) and it stands beside them. Height then follows the head size. Off: Height is the size in metres, so the game must use scale 1 for the file, not KayKit's 0.78.
